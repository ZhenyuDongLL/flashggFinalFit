| Script | Output |
|--------|--------|
| `scripts/run_resolved.sh` | `outputs/resolved/.../combine/combine_resolved.log` |
| `scripts/run_boosted.sh` | `outputs/boosted/.../combine/combine_boosted.log` |
| `scripts/run_all.sh` | `outputs/all/.../combine/combine_all.log` |
